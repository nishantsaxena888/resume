2. Describe a specific example where you designed a complex data model and then optimized it to improve performance (what you changed and the measured impact). Also list the databases you have strong hands-on experience with?

Answer:
Databases: PostgreSQL, MySQL, SQL Server, MongoDB, DynamoDB, Redis, **Elasticsearch** (Deep Hands-on).
Example: At Mind Master Solutions, I architected a highly complex data model for a Document Extraction platform handling Invoices and POs where the sheer volume of fields and data distributions constantly fluctuated between diverse clients.
 What I changed: I implemented an "Everything is a Source" philosophy. 
 Rather than hardcoding database columns for every possible field, I extended **Django/DRF** natively to generate dynamic schemas on the fly. 
 I built custom generic connector wrappers combining AWS Textract, docTR, and Tesseract outputs into this unified schema. 
 Measured Impact: This abstraction dramatically optimized our data ingestion pipeline speed. 
 It enabled seamless, zero-downtime integration with diverse enterprise ERPs, and allowed the system to absorb entirely new document formats with zero structural backend code changes.
